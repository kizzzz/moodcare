# 「心晴」情绪日记与自我关怀 — 产品结构与 UI 色彩设计

> 版本 v1.0 ｜ 2026-11-05 ｜ 前序文档：01-调研报告
> 产品主线：**简洁 · 好用 · 有用** ｜ 本文档重点：产品结构 + UI 设计语言 + 情绪色彩系统

---

## 一、产品定位

| 项 | 内容 |
|---|---|
| 产品名（建议） | **心晴** ｜ 备选：微光、暖屿 |
| Slogan | **情绪像天气，来了也会走。** |
| 一句话定位 | 给年轻人的 30 秒情绪日记 + AI 自我关怀伙伴 |
| 核心隐喻 | **天空与天气**——情绪是天上的云雨晴风，记录它、看它流动，而不是评判它。天气隐喻天然去医疗化（对抗 31% 病耻感），且与"每日看天气"的习惯同构，降低记录心理门槛 |
| 目标用户 | 18-25 岁学生与职场新人（详见调研报告用户画像） |
| 伦理边界 | 自我关怀工具，不是治疗产品；内置危机分流，不冒充专业咨询 |

**为什么天气隐喻贯穿全局**：
- 去病耻感："今天有雨"不等于"我有病"，天气是中性的、人人都有
- 天然解释情绪无常：自我关怀的核心话术"情绪如天气，会来也会走"直接可视化
- 色彩系统有了统一叙事：四类情绪 = 四种天气（风起/日晴/夜雨/微风），今日记录 = 今日的天空

## 二、设计原则（简洁·好用·有用 → 8 条可检验准则）

**简洁**
1. **一屏一事**：记录流程每步只问一个问题；首屏区块 ≤3
2. **点选优先于输入**：存在全程 0 打字的完整记录路径
3. **功能密度克制**：不做社区、不做信息流、不做积分商城（对应调研：社区噪音、功能堆砌是竞品差评源）

**好用**
4. **30 秒上限**：点选路径完成一次记录实测 ≤15 秒，含输入 ≤30 秒
5. **跳过不惩罚**：任何步骤可跳过；无断签警告、无红色感叹号；允许"每周 3 次"宽松目标
6. **深夜友好**：22:00 后自动切换暖色深夜模式（情绪表达高峰在深夜，蓝光抑制褪黑素有明确科学依据）

**有用**
7. **两次反馈**：每次记录必有即时回应（AI 自我关怀回应 + 微行动）；每周必有延迟洞察（周报）
8. **匹配而非随机**：所有调节内容（歌单/呼吸/微行动）按"当下情绪状态"匹配推荐，不搞通用推送

## 三、信息架构（4 Tab + 中央记录按钮）

```
┌─────────────────────────────────────────────┐
│   今日      洞察      ⊕记录      关怀      我的   │
└─────────────────────────────────────────────┘
```

中央凸起大按钮 = 记录入口（唯一核心动作，永不改变位置）。四个 Tab 均为"看与被照顾"，只有 ⊕ 是"做"。

```
心晴
├── 今日 (Home)
│   ├── 问候 + 日期（"11月5日 · 星期四"）
│   ├── 今日天空卡 ← 记录前：柔和引导；记录后：情绪色渐变
│   ├── AI 回应 + 微行动卡片（当日未完成时轻提示，不催促）
│   └── 最近日记流（时间线：彩色圆点 + 情绪词 + 一句话）
│
├── 洞察 (Insight)
│   ├── 本周情绪色带（7 个彩色圆点，"情绪彩虹"）
│   ├── 情绪曲线（周 / 月切换）
│   ├── 触发因素 Top 3（"本周的低落，2 次与' deadline '相关"）
│   ├── 情绪分布环 + 高频情绪词
│   └── 周报卡片（每周日 20:30 推送，见核心流程三）
│
├── ⊕ 记录（核心流程，全屏，详见流程一）
│
├── 关怀 (Care) —— 自助调节工具箱
│   ├── 呼吸：4-7-8 呼吸 / 箱式呼吸 / 五指呼吸（60 秒起）
│   ├── 冥想：3-10 分钟引导音频（身体扫描/接纳/睡眠）
│   ├── 心境歌单：按当下情绪匹配（低落→先共情后引导的歌单曲线）
│   ├── 微行动库：行为激活卡片（出门走 5 分钟/给朋友发条消息/喝杯温水…）
│   ├── 自我关怀练习：给明天的我写一句话 / "如果是好朋友遇到这件事"引导
│   ├── 睡前放松（与深夜模式联动）
│   └── 需要更多帮助：热线与专业资源入口（常驻底部，见风险设计）
│
└── 我的 (Me)
    ├── 隐私中心：应用锁 / 指纹解锁 / 数据本地导出 / 一键删除 / 匿名模式
    ├── 记录节奏：宽松目标设置（默认每周 3 次，可改每日）
    ├── 外观：深夜模式（自动/常开）/ 主题色微调
    └── 帮助与热线资源
```

**桌面小组件（留存的第二入口）**：4 个情绪色圆点，点一下即完成一条"简记录"（有调研证据：小组件用户留存 +25%）。

## 四、核心流程

### 流程一：30 秒记录（产品的灵魂，一步一屏，全程可跳过）

```
入口：中央⊕ / 小组件 / 定时提醒（可关）
   ↓
Step 1「此刻的心情是什么天气？」（~8 秒）
   四色天气卡 2×2：风起🔴 日晴🟡 夜雨🔵 微风🟢
   → 点选后展开该族 6 个细分词（如夜雨：低落/难过/疲惫/孤独/空落/提不起劲）
   → 词即记录，无需确认键
   [科学依据：情绪标注降低杏仁核活跃度；四象限 = Yale Mood Meter 成熟范式]
   ↓
Step 2「发生了什么？」（~8 秒，可跳过）
   触发标签多选：学习/工作/人际/家人/恋爱/身体/睡眠/独处/刷手机/说不清…
   强度滑条：默认跟随所选词的唤醒度，可不动
   ↓
Step 3「想说点什么吗？」（~10 秒，可跳过）
   三个选项并排：🎙 说说（语音转文字）｜✏️ 写一句（单行输入，非长文）
   ｜💬 聊两句（进入 AI 对话式记录，AI 温和追问后自动结构化归档）
   底部灰字："不想说也没关系，跳过"
   ↓
生成回应（1 秒内）
   ① AI 自我关怀回应卡（三段式 ≤3 句，见下）
   ② 微行动 3 选 1（与当前情绪匹配，见下）
   ③ 今日天空卡亮起今日情绪色（柔光动效 ≤800ms）
```

**AI 回应三段式**（自我关怀理论工程化，非讨好式共情）：
1. 正念确认：命名并接住情绪（"被 deadline 追着跑的焦虑，很真实"）
2. 共通人性：正常化（"很多人在被追赶的时候都会这样"）
3. 自我善意：一句对自己的温柔话 or 一个 30 秒微行动邀请

**微行动 3 选 1 规则**（行为激活，证据最强的干预）：
- 低落/疲惫（夜雨）→ 低门槛身体类：喝杯温水、开窗站 1 分钟、4-7-8 呼吸 60 秒
- 焦虑/烦躁（风起）→ 释放类：写下最坏情况 3 行、快走 5 分钟、撕纸/握拳放松
- 平静/愉悦（微风/日晴）→ 存档类：存一句"今天值得记住的瞬间"、感恩记录
- 完成 → 轻轻打勾 + 一句反馈（"今天也照顾了自己 🌱"），不搞金币不搞连胜

### 流程二：低落时刻的即时关怀（嵌入流程一）

检测到"夜雨"族 + 高强度（连续 2 次或强度 ≥4）：
- AI 回应语气温柔和、句子更短
- 回应卡下方多一行："需要一个拥抱吗？" → 展开一段 60 秒的引导式自我安抚（把手放在心口 + 3 次深呼吸）
- 连续 3 天夜雨 → 温和推送周报预告 + 关怀工具引导（不诊断、不说"你可能抑郁"）

### 流程三：周报（每周日 20:30 推送，"有用"的延迟反馈）

```
本周的天空 🌈
├── 情绪彩虹：7 个色点连成的本周色谱
├── 一句洞察："你的低谷 2 次出现在周日晚——那正是 deadline 前夜"
├── 触发因素 Top 3 排行（横向条形，情绪色着色）
├── 值得保留的：本周你记录过的 1 个日晴/微风瞬间（回看正能量时刻）
└── 下周一个小建议（行为激活微目标，非任务清单）
```

### 流程四：危机安全网（常驻，不喧哗）

- 关怀页底部 + 设置内常驻"需要更多帮助"：心理援助热线列表、就医指引
- 记录中检测高危词（自伤等）→ 界面不突变红、不弹警告，改为温和卡片："这些时刻值得被认真对待，要不要看看能立刻帮到你的人？" + 一键热线/信任的人
- AI 对话永不扮演治疗师：涉及专业边界时明确说"这个问题我陪不了你，但他们可以"

## 五、功能模块与调研依据对照

| 模块 | 功能 | 依据（调研报告） |
|---|---|---|
| 记录 | 四象限点选 + 细分词 + 标签 + 可选语音/文字/对话 | 断更主因是摩擦；情绪标注/粒度科学 |
| AI 对话式记录 | "聊两句"把倾诉自动结构化为档案 | 56% 青年向 AI 倾诉但无档案沉淀 |

| 隐私中心 | 应用锁/本地导出/匿名/删除 | 隐私是地基；监管敏感期 |
| 小组件 | 4 色点一键简记录 | 小组件留存 +25% |
| 宽松目标 | 默认每周 3 次、无断签惩罚 | 头 10 天流失；打卡羞辱是反面教材 |

## 六、UI 设计语言

### 6.1 形状与质感

- **圆角**：卡片 20-24px、按钮全圆角胶囊、情绪词 chip 16px——圆润 = 安全感，无尖角
- **质感**：柔和的多层阴影（弥散大、透明度低），卡片如"纸片浮起"，不用描边硬框
- **触摸目标**：≥44pt；情绪词选项为大 chip（高 ≥48px），闭眼也能戳中
- **字体**：中文用系统圆润黑体（iOS 苹方/ HarmonyOS Sans），标题可用圆体；正文 16pt、情绪选项 17pt 加粗
- **触感**：选词、完成记录时轻震动反馈（iOS Haptic）
- **动效**：全局缓入缓出 0.3s；唯一的"仪式感"动效 = 记录完成后今日天空亮起（柔光扩散 ≤800ms）——动效只服务于"被接住"的情绪体验，不炫技

### 6.2 文案语气（UI 的一部分）

- 全程"天气预报员 + 温柔朋友"口吻：陈述、邀请，永不命令、永不感叹号轰炸
- 空状态示例："今天的天空还空白着——想看看此刻的天气吗？"（而非"你还没记录！"）
- 所有负向状态的去红字化：不用红色警告，用暖灰 + 温和措辞

## 七、色彩系统（本文档核心）

> **设计哲学：背景静，情绪动。**
> 环境层（底色、卡片、文字）如安静的天空，永远低饱和；表达层（情绪色）是天上的天气，是全 App 唯一被允许"有颜色"的主角。环境越安静，情绪越被看见。

### 7.1 科学依据（6 条，全部来自色彩调研）

1. **色相 = 效价**：跨文化色彩-情绪调查（30 国 4598 人，r=.88）证实红=紧张/爱怒、黄=快乐、蓝=安宁的映射跨文化稳定
2. **饱和度/明度 = 唤醒度**：Wilms & Oberfeld（2018）等证实高饱和高明度 → 高唤醒；去饱和 → 低唤醒。同族情绪可用饱和度梯度区分"焦虑 vs 压抑"
3. **四象限范式**：Yale Mood Meter（红=高能不悦、黄=高能愉悦、蓝=低能不悦、绿=低能愉悦）是情绪追踪产品最成熟的配色范式
4. **绿 = 恢复**：注意力恢复理论（ART）与压力恢复理论（SRT）支持自然绿用于"关怀与恢复"场景
5. **深夜暖色 = 刚需**：夜间蓝光抑制褪黑素（哈佛）；睡前记录场景必须降蓝光
6. **不只靠颜色**：8% 男性色觉障碍；WCAG 要求颜色必须叠加 emoji/文字/形状冗余编码

### 7.2 环境层（安静的天空）

| Token | 亮色模式 | 深夜模式（22:00 自动） | 用途 |
|---|---|---|---|
| `bg/base` | `#FAF6F0` 暖米白（奶油纸感） | `#241F1A` 暖炭（去蓝光） | 页面底色 |
| `bg/surface` | `#FFFDF9` | `#2E2820` | 卡片 |
| `bg/surface-2` | `#F3EDE4` | `#382F26` | 次级卡片/输入底 |
| `ink/primary` | `#3D3229` 暖深褐（纸上的墨，非纯黑） | `#EAE0D3` | 主文字 |
| `ink/secondary` | `#8A7E72` | `#A99C8D` | 次文字 |
| `ink/tertiary` | `#B5AA9D` | `#7A6F63` | 弱提示/占位 |
| `line/hairline` | `#EFE8DE` | `#443B31` | 分割线 |
| `brand/ember` | `#D97757` 陶土杏（品牌主色） | `#C8825F`（降饱和提亮） | 主按钮/强调 |

设计说明：
- **不用纯白纯黑**：暖米白 + 暖深褐营造"奶油纸日记本"质感，温暖且不刺眼——与 Calm 深蓝（睡眠导向）、Headspace 亮橙（活力导向）错位，占据"温暖包容"的心智
- **品牌色只做"工具色"**：陶土杏用于按钮与强调，**不参与情绪表达**——情绪色的舞台不被打扰
- **深夜模式不是反色**：是整体降低亮度 + 色相偏暖的独立配色（情绪色同步提亮一档保证对比度），22:00-6:00 自动切换，可在设置改手动

### 7.3 表达层：四族情绪色（会说话的天气）

每个情绪族 = 3 档色阶：`tint`（浅，用于背景/低唤醒）/ `main`（中，圆点与图表主色）/ `deep`（深，文字与高唤醒）。

**饱和度规则**：高唤醒词（焦虑、兴奋）用 main/deep；低唤醒词（压抑、平静）用 tint/main——同一族内靠饱和度区分强度，有科学依据（见 7.1-2）。

| 情绪族 | 天气意象 | tint | main | deep | 词库（6 词） |
|---|---|---|---|---|---|
| 🔴 风起 | 高能量·不愉快 | `#F9E3DA` | `#DE7A5C` | `#A84A30` | 烦躁、焦虑、愤怒、紧张、委屈、有压力 |
| 🟡 日晴 | 高能量·愉快 | `#FBF0D4` | `#E3A83E` | `#8F6A16` | 开心、兴奋、期待、惊喜、自豪、有干劲 |
| 🔵 夜雨 | 低能量·不愉快 | `#E1EAF2` | `#7195B5` | `#3E6484` | 低落、难过、疲惫、孤独、空落、提不起劲 |
| 🟢 微风 | 低能量·愉快 | `#E4EFE3` | `#8FAE8B` | `#587A56` | 平静、放松、安心、舒服、淡淡的幸福、感恩 |

- 每族色相选择均为**中低饱和 + 微降明度**的柔和档位：情绪色需要被识别，但绝不能刺激正在情绪低谷的用户（Baker-Miller 粉的教训：镇静靠整体低饱和环境，不靠某个"神奇颜色"）
- **双重编码**：所有情绪色永远与 emoji + 情绪词 + 象限位置同时出现，任何地方不裸用颜色区分（无障碍）
- 蓝/绿两族在色盲视角下易混：叠加 emoji（🔵🟢）与象限位置（左下 vs 右下）三重冗余

### 7.4 恢复场景色（关怀工具箱专用）

| 场景 | 配色 | 依据 |
|---|---|---|
| 呼吸/冥想 | 暮色渐变：`#2C3A52` → `#6E5B7B` → `#C8825F`（深蓝夜空过渡到地平线暖光） | 夜晚收敛意象；暖光收尾暗示"安全着陆" |
| 冥想完成页 | 鼠尾草绿 `#8FAE8B` 主导 | ART/SRT：自然绿 = 恢复 |
| 心境歌单 | 沿用情绪四族色标 | 音乐需匹配当下情绪（研究：成功率约五成，匹配是前提） |
| 睡前放松 | 深夜模式 + 烛光橙 `#C8825F` 点缀 | 降蓝光科学依据 |

### 7.5 动态色彩策略（3 个创新机制）

**① 今日天空卡 = 你的情绪天空（核心视觉记忆点）**
- 未记录：晨雾灰蓝 `#D8DDE2`，配文案"今天的天空还空白着"
- 已记录：卡片渐变 = 今日情绪族 tint→main（如记录"焦虑" → 珊瑚暮色渐变）
- 一天多次记录：渐变按时间纵向分段，形成"今日天气带"——**你的日记越长，天空越丰富**
- 今晚回看 = 看自己的一天如何流过（正念的"观察情绪如天气"直接可视化）

**② 关怀降饱和：情绪越低，界面越柔**
- 检测到夜雨/高强度记录后 30 分钟内，全局环境色自动降饱和 10%、降对比（"柔光模式"）
- 原则：用户情绪低谷时，产品自己先冷静下来——绝不用高饱和撞色"振作起来！"式刺激用户

**③ 情绪彩虹的收集感**
- 洞察页本周 7 色点、年度"天空合集"（12 个月的今日天空卡缩略墙）
- 把"记录"从任务变成"收集自己的天空"——进步感可视化，对抗头 10 天流失

### 7.6 对比度与无障碍清单

- [ ] 正文文字对比度 ≥4.5:1（WCAG AA），大字号 ≥3:1
